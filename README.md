## 📁 结构

```
music-player-exp2/
├── index.html       # 页面入口
├── index (1).html   # 实验过程中的历史版本备份
├── audio.css        # 播放器样式（从 HTML 中抽离）
├── js/audio.js      # 播放器逻辑（音频 + 视频联动）
├── js/播放时间格式化代码.txt  # 时间格式化函数草稿
├── img/             # 图标与背景资源
├── mp3/             # 音频文件
└── mp4/             # 背景视频文件
```

## 🛠 技术栈

- **HTML5** — `<audio>` + `<video>` 双媒体元素联动
- **CSS3** — Flexbox 布局、动画、响应式
- **Vanilla JavaScript** — 无框架、无构建工具

## 🚀 本地运行

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```
